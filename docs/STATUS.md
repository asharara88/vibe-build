## Words used here

A *branch* is a named line of work in the repository; a *commit* is one saved step on it; a *pull request* is a proposed set of changes that can be read before it is merged. The *integration branch* `claude/stage-1` is where work is gathered once it has been reviewed; not everything on it is tested, and the table below says what is; `main` is changed only by the owner. A *container* is a separate box in which a program runs. A *stack* is the set of tools an app is written with (the first candidate is TypeScript with Next.js, a web framework; the second is Django, a Python web framework). A *licence* is the permission that comes with software someone else wrote; *LGPL* and *MPL* are licences that carry duties when the software is passed on. A *licence code* (L9, L10, L11) is the plan's name for one licence condition. A *waiver* is the owner's recorded decision that no stack comparison will be made. A *checkpoint* is one of the plan's five meeting points with the owner (0 to 4). A *hold* is money set aside before a model call; to *reconcile* a hold is for the owner to record what the call really cost. A *stand-in* is a fake used for tests in place of the real thing, such as a fake provider, which costs nothing. A *proof row* is one line of the design note's table of things that must be shown. The *head* of a branch is its latest commit. *Development-only* packages are tools used while building, as opposed to *shipped* packages, which run inside the finished program. In the baseline: the *gateway* is the part meant to be the one door to the AI model; the *egress proxy* is the part that filters the requests sent through it; the *sandbox manager* creates a project's containers; the *app spec* is the machine-readable brief; the *event log* is the record of what happened; the *template* is the starter a generated app begins from; the *exporter* (not built) hands a finished app over. An *environment variable* is a named setting given to a session by its *cloud environment*, the saved set-up a session runs in. A *provider* is the company whose AI model is called; the *engine* is the part that asks the model to write code; the *scripted engine* is a stand-in for it that applies fixed, known changes and calls no model; the *model key* is the secret that lets the builder call the provider and be billed. `psycopg` is the database driver Django needs. A *lock file* is the full list of exact packages an install uses, for every kind of computer. In the plan's tables, *Key* means the model key is set (after checkpoint 1), *Candidate* that the demo candidate is chosen, *Server* that a demo server exists. The *cloud session's proxy* is a gatekeeper of the cloud machine this work runs on, not part of the builder. *Docker's default network* is a private network Docker makes on the machine; a container on it does not share the machine's own network. A *port* is a numbered door on an address, one per service; the *loopback address* is a machine's address for talking to itself, and a service that *listens on every address* can also be reached at the machine's other addresses. *Isolated* here means a container cannot reach what it is not meant to. A *probe* is a small program run inside a container that tries to reach places and records each result; each attempt has a label (A2, D1, F4 and so on), listed in the evidence file. A *name lookup* turns a host's name into its address. An *HTTP status* is the numbered reply of a web server: 200 means answered, 301 moved elsewhere, 403 refused, 405 not accepted in that form. *HTTPS* is the web's secured form, usually on port 443 (plain HTTP on port 80); a *certificate* is what a program checks before it trusts an HTTPS answer. A *tunnel* (a CONNECT request) asks a proxy to join the caller to another host. The *proxy variables* are the settings (`HTTPS_PROXY`, `HTTP_PROXY`) that tell a program which proxy to send its requests through; `--network host` is the Docker setting that makes a container share the machine's own network.
