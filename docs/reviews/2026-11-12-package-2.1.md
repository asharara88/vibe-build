A *should-fix* point is one a reviewer asked to be fixed but did not rate as blocking a merge; a *note* is a smaller point. No reviewer in any round rated anything blocking.

**Words used here.** A *lens* is the one angle a reviewer is told to read from. A *checker* is an agent given a finding and told to show it wrong; a finding is *confirmed* when both checkers agree it is real. A *re-reader* is a fresh reviewer who reads the answers to an earlier round. A *rebase* moves a branch's commits onto a newer starting point, which gives them new names. The *applier* is the small program that writes a step's fixed files inside the engine container. A *stand-in runner* replays the applier's output with no container. An *event handler* is the builder's code that receives each event the engine reports; an *async handler* can fail later, through a *promise* (a pending result) that *rejects*. A *named pipe* is a special file two programs use to talk; git does not list it. The *reset* puts a failed step's workspace back to the last commit; `git clean -ffd` is the git command it uses to remove new files and folders. A *misbehaving engine* is a short made-up command, run in the engine container in place of the applier, that does what a faulty engine might.
