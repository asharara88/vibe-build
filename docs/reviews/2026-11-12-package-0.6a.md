A *blocking* finding is one a reviewer rated as stopping a merge; a *should-fix* point is one a reviewer asked to be fixed but did not rate as blocking; a *note* is a smaller point. Of pull request #22's reviews, three findings were rated blocking, all in round 1, and all were answered before round 2, which judged them resolved. The record update after the merge had its own review, with two blocking findings (last section).

**Words used here.** A *lens* is the one angle a reviewer is told to read from. A *confirmed* finding is one that two more agents, each told to show it wrong, confirmed. A *re-reader* is a fresh reviewer who reads the answers to an earlier round. The *probe* is the small program that makes the attempts from inside each container; the *harness* is the builder's code that runs it and reads its output. A *control* is a test run once with its fix removed, to show that the test can fail. A *unit test* is a small automated test of one piece of code, run without containers; the *suite* is all the automated tests together; the *type check* checks that the code's parts fit together as written; the *licence check* is the project's rule on the licences of the packages it uses. The *loopback address* (127.0.0.1) is a machine's, or a container's, address for talking to itself; a service *listens* on an address when it takes connections there, and one that listens on every address of the machine can also be reached at its other addresses (its *listen address* says which). *Docker's default network* is a private network Docker makes on the machine; a container on it does not share the machine's own network. The *comparison container* is the one on Docker's default network, which is not a project container. *Group G* is the attempts toward the machine's own address on Docker's default network (its *gateway address*). Each attempt has a label (A1, B2, F4 and so on), listed in the evidence file. A *port* is a numbered door on an address, one per service: HTTPS, the web's secured form, usually uses port 443, and plain HTTP port 80. A *certificate* is what a program checks before it trusts an HTTPS answer. A *tunnel* (CONNECT) is a request asking a proxy to join the caller to another host. *UDP* is a kind of network traffic sent without opening a connection (name lookups use it); an *abstract socket* is a door between programs on the same machine that has a name but no file; *Docker's socket* is the door through which programs give Docker orders; *IPv6* is the newer form of internet address. The *review bot* is an automated reviewer on GitHub; it reports in one *summary comment* on the pull request, which it edits in place after each read, so an earlier result is no longer shown there.
