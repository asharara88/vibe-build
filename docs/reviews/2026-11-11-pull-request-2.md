## How to read the states

A finding is **closed** only when the package that answers it is tested under `docs/BUILD-PLAN.md` (its "Done means" run and passed, an evidence file, an independent reviewer's findings closed on the commit that was merged) and the evidence named here supports closing it. Otherwise it is **open**. For a safeguard, three words and no others say how far it has got: **shown** (run, with evidence), **designed** (written, not run), **not done**. A design correction on paper never closes a finding about how the running system behaves.

Every finding below is about that cap or about the holds design that replaces it. **For all ten, the design is corrected on paper. Since 13 November 2026 package 1.2, merged with pull request #12 at `90484c1` and marked tested, is the running control for part of it, shown against a stand-in provider only** (`evidence/2026-11-12-package-1.2/holds.md`); the rows below say what that shows. A stand-in shows what the gateway does with the answers it is given, not how the real provider counts, bills or fails (build plan section 8, rule 3; package 2.3).
